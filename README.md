# HNIU 校园网自动登录工具

面向湖南信息职业技术学院（HNIU / 湘信职院）校园网的 Windows 自动登录小工具。双击即可自动完成校园网认证页面的登录流程，省去每次连网后手动打开浏览器、输入账号密码的步骤。

## 系统要求

- Windows 7 / 8 / 8.1 / 10 / 11（64 位）
- 已连接到校园网（HNIU）Wi-Fi 或有线网络

## 使用教程

1. 打开本仓库的 **Releases** 页面，找到最新版本 **v1.1**。
2. 在 Assets 中下载 `HNIU校园网认证客户端 By LiYH v1.1.exe`。
3. 把下载好的 exe 文件**复制到桌面**（或任意你方便找到的位置）。
4. 双击 exe 即可直接运行，无需安装、无需配置。
5. 程序会自动完成校园网认证；登录成功后即可正常访问外网。

> 提示：第一次运行时 Windows SmartScreen 可能会提示“未知发布者”，选择“仍要运行”即可。

## 常见排障

### 登录超时

如果程序运行后一直卡在“登录中”或提示登录超时：

- 请确认电脑**只连接到了校园网这一个外部网络**。
- 关闭其他可能抢占出口的网络，例如：手机热点、其他 Wi-Fi、VPN、代理软件（Clash / v2ray / 系统代理等）。
- 断开后重新连一次校园网，再双击运行 exe。

### 其他问题

- 确认当前网络环境确实是湘信职院校园网（HNIU），其他运营商或家庭网络下本工具不适用。
- 如果杀毒软件拦截，请将 exe 加入信任列表后重试。
- 如仍无法登录，可手动在浏览器打开校园网认证页，确认账号密码本身是否可用。
